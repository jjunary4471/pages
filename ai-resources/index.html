02영상 제작

2-1. AI 장편영화 제작 데이터를 내 작업에 옮기는 6단계

보낸 사람 프롬왓 · 원문 Notion · 원본 데이터 Higgsfield · Hell Grind (영어, Higgsfield 계정 필요, 무료)

Higgsfield가 자사 플랫폼만으로 만든 95분 AI 영화 Hell Grind(제작비 50만 달러 미만, 15명, 생성 14일, 누적 생성 115,446건, 2026년 5월 칸 상영)의 브리프·프롬프트·에셋·스킬 파일을 2026-08-04에 전부 공개했습니다. 프롬왓 글은 그 11만 건 중 "뭘 읽고 뭘 클로드·코덱스로 옮겨 쓸지"만 추린 것입니다. 핵심 한 줄:

에셋을 먼저 잠가라. 캐릭터·장소·소품이 전부 확정되고 스트레스 테스트를 통과하기 전에는 단 한 컷도 생성하지 마라.

공개된 자료와 용도

자료내용언제 쓰나
제작 브리프문제별 해결 과정과 판단 근거전체 흐름부터 잡을 때
장면별 프롬프트실제 사용 원문 (편당 3,000~4,000단어)뼈대를 그대로 가져올 때
에셋 라이브러리캐릭터·장소·소품 시트 전량인물이 흔들릴 때
샷리스트블록별 샷 번호·길이·프롬프트긴 장면을 쪼갤 때
CINEDANCE 스킬영상 프롬프트 작성 규칙 파일클로드에 물려 쓸 때
LIRA 스킬이미지 프롬프트용, 모델별 약점 반영에셋 만들 때
ACTING 스킬연기·표정·행동 작성 체계인물이 인형처럼 굳을 때

스킬이란? 규칙을 적어 둔 마크다운 파일 하나. 클로드가 스스로 불러와 그 규칙대로 일합니다. 매번 "이렇게 써줘, 이건 하지 마"를 치는 대신 파일이 대신하므로 세션마다 규칙이 리셋되지 않고 토큰도 줄어듭니다.

따라 하는 순서 (순서를 바꾸면 뒤에서 비용을 치름)

  1. 스킬 파일 3개부터 얹는다. CINEDANCE·LIRA·ACTING을 내려받아 클로드 프로젝트 또는 코덱스 작업 폴더에 넣는다. 셋 다 마크다운이라 어디서든 읽힌다.
  2. 에셋부터 잠그고 이름 사전을 정한다. 캐릭터·장소·소품이 확정되기 전엔 본 컷을 만들지 않는다.
    • 태그 규칙: 인물은 @roco, 장소는 @loc_cave_front처럼 정하고 문서·프롬프트·툴 화면 어디서나 그 이름만 쓴다. 생김새를 매번 문장으로 풀지 않아 글자 수도 준다.
  3. 설명글(디스크립터)과 스타일 문단을 상수로 뺀다. 에셋 = 설명글 + 참고 이미지 한 쌍. 매 프롬프트에 그대로 들어가는 문단은 상수 파일 한 곳에 두고, 한 곳만 고치면 모든 샷에 반영되게 한다. 복붙하면 수정 때 어긋난 버전이 섞인다.
  4. 열 번 돌려서 열 번 다 알아보는지 본다 (스트레스 테스트). 포즈·조명을 바꿔 10번 생성, 10번 다 같은 인물이어야 통과. 다른 인물 옆에 세워서도 확인. 실패하면 모델이 아니라 설명글을 고친다.
  5. 프롬프트는 뼈대 15항목 순서로 채우고, 샷리스트는 블록별 파일로 쪼갠다.
    • 뼈대: 장면 상황 → 참고 에셋과 역할 → 공간 지도 → 첫 프레임 배치 → 촬영 방식 → 렌즈 → 카메라 움직임 → 초 단위 동작 → 물리 → 조명 → 소리 → 연기 → 스타일 → 품질 → 제약
    • 길이는 문제가 아니다. 한 구간에 여러 동작을 몰아넣는 게 문제.
  6. 한 번에 한 줄만 고치고 로그를 남긴다. 통째로 다시 쓰면 잘 되던 부분까지 잃는다. "바꾼 내용 + 결과 판정"을 로그 파일로 남겨 클로드와 같이 둔다. 10~15번 안에 안 나오면 문장이 아니라 컷을 쪼갠다.
빠뜨리면 바로 티 나는 8가지
  1. 캐릭터 시트 정면 전신에서 머리를 지운다. 시트는 얼굴 클로즈업 / 정면 전신 / 후면 전신 3장. 정면 전신에 머리가 있으면 모델이 작고 흐릿한 얼굴을 가져가 망가진다.
  2. 시트는 일부러 심심하게. 무채색 배경, 평평한 조명, 보정 없는 피부. 필름 그레인을 시트에 구우면 모든 장면에 끌고 다닌다. 영화적 느낌은 장소 에셋과 영상 프롬프트가 맡는다.
  3. 상태가 바뀌면 다른 에셋. 젖은/다친/옷 갈아입은 상태, 장소의 낮·밤·비는 각각 별개 에셋. 나누는 쪽이 싸다.
  4. 첫 1초는 무조건 넓은 화면. 대사도 동작도 없는 1초를 넣으면 모델이 누가 어디 있고 빛이 어디서 오는지 찍어 두고 유지한다. 빼면 인물들이 자리를 바꾼다.
  5. 공간 지도를 장면마다 쓰고 모든 컷에 붙인다. 기준 물체 위치, 카메라 위치, 넘지 않을 선을 몇 줄로. 모델은 앞 컷을 기억 못 한다.
  6. 참고 자료마다 역할을 이름 붙인다. 안 적으면 모델이 알아서 정하는데 대개 틀린다. 장소 참고에는 "시작 프레임으로 쓰지 말고 구도·각도·색을 물려받지 말라"고 직접 금지한다.
  7. 감정이 아니라 몸을 쓴다. "슬프다" 대신 "턱이 물렸다 풀린다", "코로 숨을 얕게 내쉰다". 속마음 한 줄 + 눈 깜빡임 리듬 + 1~2초마다 미세한 움직임 하나.
  8. 금지는 긍정문으로. "뒤로 넘어지지 않는다" ✗ → "앞으로 엎어진다" ○. 인원은 "정확히 세 명". 나이는 어떤 언어로도 쓰지 않는다. 대사는 소리 구역에만.

2-4. 한 줄 프롬프트로 영상 편집 (Diffusion Studio)

보낸 사람 채문기 · 원문 Notion · 도구 diffusion.studio (회원가입 필요, macOS/Windows/브라우저)

  1. diffusion.studio 접속 → 회원가입.
  2. New project → 작업물을 저장할 PC 폴더 하나 지정.
  3. 왼쪽 메뉴에서 영상 파일 가져오기(import).
  4. 영상을 하단 타임라인으로 드래그.
  5. 오른쪽 에이전트 입력창 아래에서 비율 선택 (Vertical 9:16 / Wide 16:9 / Square 1:1 등).
  6. 입력창에 한 줄 입력 → 자동 편집.
Prompt · 무음 구간 자동 컷
영상 내에 음성이 있는 부분만 남기고, 목소리가 비어 있는 구간은 알아서 잘라서 편집해줘.

원문 페이지의 예시는 이 한 가지뿐이고, 끝은 "직딩스쿨" 카카오 오픈채팅 가입 유도로 끝납니다.
