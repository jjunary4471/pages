## 페이지의 네 부분

1. **개념** — 설명 본문 + 만져 볼 수 있는 그림(JS). 설명은 글쓴이가 직접 쓴다 (아래).
2. **예제 따라 풀기** — 한 단계씩 펼치는 풀이. 각 단계에 "왜" 한 줄.
3. **문제** — 종이에 풀고 답을 넣으면 즉시 채점. 틀리면 힌트. 정답은 base64 로만 숨김(공부용이지 시험용이 아니다).
4. **파이썬으로 만들어 보기** — Pyodide 로 브라우저 안에서 실행. 함수 몸통은 `raise NotImplementedError`, 실행하면 테스트. 코드 정답은 접힘.

진도(문제 정답, 파이썬 통과, 쓴 코드)는 브라우저 localStorage 에 저장된다.

## 집필 규칙 — 개념 설명은 직접 쓴다

페이지의 노란 점선 상자(`<div class="draft">`)가 설명을 쓸 자리다. 상자 안에는 **무엇을 설명해야 하는지 안내 질문**만 있다. 공부는 이 상자를 채우는 과정에서 일어난다.

- 상자 하나를 `<p>` 몇 개로 바꾼다. 안내 질문의 순서를 따라가면 된다.
- 중학교 1학년에게 말하듯이. 용어가 처음 나오면 바로 다음에 예를 든다.
- 한 문단 = 한 생각. 세 문장 넘어가면 자른다.
- 수식은 유니코드로 (2² × 3 × 5). 위첨자는 ²³⁴ 또는 `<sup>`.
- 다 썼으면 Claude 에게 검수를 받는다: 틀린 곳, 중학생에게 어려운 말, 빠진 예시.
- 모든 상자를 채우면 머리의 "✍️ 집필 중" 배지를 지우고 목록(`pages/index.html`)의 카드 설명을 고친 뒤 푸시한다.

Claude 가 만드는 것: 페이지 틀, 대화형 그림, 예제 단계, 문제와 채점기, 파이썬 과제와 테스트, 그림 파일.
내가 만드는 것: 개념 설명 본문, 손풀이 답, 파이썬 코드.

## 새 단원 추가
