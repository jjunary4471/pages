AWS 서비스 사전

AWS Certified AI Practitioner 공식 연습 문제(20문)의 문제와 보기에 나온 AWS 서비스·기능 0개를 정리했습니다. 각 서비스를 한 줄 요약 → 시험 포인트 → 문제에서 이 단어가 보이면 → 헷갈리는 짝 순서로 적었습니다.

Q번호는 2026-11-22에 푼 공식 연습 문제 세트의 문항 번호입니다. 점선 칩은 문제에는 없지만 짝으로 함께 알아 둘 것입니다.

02서비스 카드

이름만 보고 무엇을 하는 서비스인지 소리 내어 말해 본 뒤, 카드를 눌러 확인하세요. 말로 설명하지 못한 카드만 다시 보면 됩니다.
찾는 서비스가 없습니다.
설명은 각 서비스의 AWS 공식 문서와 연습 문제 해설을 바탕으로 2026-11-22에 요약했습니다. 시험은 서비스의 세부 설정보다 “어떤 문제에 어떤 서비스를 쓰는가”를 묻습니다.
